# 产品背景（Product Context）

## 为什么做这个项目
俄罗斯方块是经典游戏，但多数在线版本要么需要注册登录、要么缺少与好友的即时对战与聊天。BearBricks 的目标是让任何人打开浏览器、输入昵称，就能和最多 3 个朋友（或 AI）立刻开一局对战。

## 解决的问题
| 现有痛点 | BearBricks 的方案 |
|---|---|
| 需要注册才能联机 | 访客身份（localStorage），零门槛 |
| 手感不标准（无 SRS/锁定延迟） | 按 Tetris Guideline 复刻核心机制 |
| 对战模式单一 | 三种模式：竞速 / 生存淘汰 / 限时赛 |
| 无交流 | 房间内轻量文字聊天 + 系统消息 |
| 作弊泛滥（客户端计分） | 服务端权威，客户端只上报输入 |

## 用户旅程（主流程）
1. 打开网页 → 自动生成访客昵称（可改）→ 进入大厅
2. 大厅入口：单人 Marathon / 单人 Sprint / 创建房间 / 房间码加入 / 快速匹配 / 设置
3. 房主选择模式（sprint / survival / timed）与参数、可补 AI → 开始
4. 倒计时 3 秒 → 对战：己方大板 + 对手小板 + 攻击指示 + 聊天侧栏
5. 结束 → 结算排名 → 「再来一局」回到房间等待状态

## 体验目标
- **手感第一**：输入到画面响应无感知延迟（本地乐观渲染）
- **公平**：方块序列由服务器生成，AI 与真人共用同一引擎
- **信息透明**：能看到对手进度/威胁（攻击预警），但看不到对方棋盘细节之外的多余信息
- **低挫败**：断线可恢复；被淘汰后转为观战仍可聊天；top-out 在 timed 模式不是终局
- **克制**：不做商城、不做排行榜持久化，界面保持干净

## 目标用户
- 想和同事/朋友快速来一局的休闲玩家（主场景：局域网/同一办公室）
- 想练手的单人玩家（Marathon / Sprint 40）
- 不要求账号、不在意跨设备同步的用户
